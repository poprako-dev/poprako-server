# PopRaKo Server README 写作建议

README 的主体建议面向第一次接触白杨子的人：先说明项目服务谁、解决什么问题，再介绍主要能力和下一步入口。具体参数、测试和发布流程放到对应文档，让维护者按需查阅。

## 首页应回答什么

GitHub 官方将项目用途、价值、上手方式、求助入口和维护者列为 README 的常见内容，并建议将较长的说明放到其他文档。这适合本项目希望降低技术密度的方向。以下篇幅和栏目安排是结合本仓库提出的编辑建议，并非 GitHub 的硬性要求。[GitHub README 指南](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes)

建议用约 600–900 个中文字完成主体，依次包括：

1. **项目介绍**：一句话说明白杨子服务汉化协作，再用一句话说明本仓库是服务端。
2. **主要功能**：用五到六条介绍项目管理、成员分工、翻校协作、成果交付、监修批注和归档。
3. **使用与参与**：区分希望使用白杨子的人和希望部署、开发服务端的人，提供各自的真实入口。
4. **反馈与许可**：链接反馈说明、贡献指南和许可证。

标题可继续使用当前的“白杨子 S · PopRaKo Server”。中文正文保持一致，产品名、代码名称和许可证标识保留原文即可。[当前 README](../README.md)

## 功能描述怎么改

优先写读者可以完成的事情。服务端能力和客户端体验应分清：后端提供上传、保存和批注接口，不足以单独证明操作“一键完成”或界面“简明易用”。现有版本说明列出了团队、作品与章节、成员分工、流程阶段、翻校内容、术语库、成品批注和导入导出能力，可据此组织业务介绍。[版本功能列表](releases/1.0.0.md)

| 当前表达 | 建议表达 |
| --- | --- |
| 全面的权限与成员身份统计与管理 | 管理团队成员，按汉化分工分配任务和权限 |
| 漫画-章节式的项目管理 | 按作品和章节管理项目，持续跟进连载进度 |
| 完整的章节级别工作流记录，准确记录……耗时 | 记录章节各阶段的进度与操作历史 |
| 简明易用的在线协作翻译器，近似实时协作 | 为在线翻译与校对提供内容保存、协作和术语管理支持 |
| 符合身体工程学的翻译-校对模式 | 删除主观评价，直接介绍翻译、校对和批注功能 |
| PSD 压缩上云，一键完成嵌字结果交付 | 支持上传和管理章节成品压缩包，便于成果交接 |
| 监修在线批注，实时反馈嵌字清晰的修正建议 | 支持在成品页面上记录监修批注，便于沟通修改意见 |

这些表述的边界来自现有业务说明：成品压缩包与供批注使用的页面是独立资源，页面提取和上传由客户端完成；章节流程和操作历史也有单独的接口验证范围。因此首页不宜将其概括成服务端自动完成压缩、实时推送或工时统计。[成品与监修说明](chapter-issues.md)、[HTTP 测试清单](../tests/integration-tests/TESTCASES.md)

## 主体示例文案

下面的文字用于展示语气和信息密度。正式 README 的使用入口应在客户端或官网地址确认后补齐；本研究不推断其公开可用状态。

> **白杨子 S · PopRaKo Server**
>
> 白杨子面向漫画汉化团队，帮助成员围绕同一部作品协作，管理从图源、翻译、校对到嵌字与监修的工作。
>
> 本仓库是白杨子的服务端，为客户端提供项目管理、成员分工、内容保存与文件管理支持。
>
> **主要功能**
>
> - **团队与分工**：支持多个汉化组使用，各自管理项目和成员，并按工作分配任务与权限。
> - **作品与章节**：按作品组织章节，跟进各阶段的进度与操作记录，方便管理长期连载。
> - **翻译与校对**：管理图源、译文和校对内容，通过术语库保持用词一致。
> - **成果交付**：管理章节成品文件，支持翻译内容的导入与导出，方便不同环节交接。
> - **监修批注**：在成品页面上记录问题位置与修改意见，方便成员沟通和修正。
> - **项目归档**：保存作品归档记录，支持导出，便于后续查阅与整理。
>
> **参与项目**
>
> 欢迎提交问题反馈、功能建议和代码贡献。反馈方式见 SUPPORT.md，开发协作要求见 CONTRIBUTING.md。
>
> **开源许可**
>
> 本项目采用 GNU AGPL v3 许可证（AGPL-3.0-only），完整条款见 LICENSE。

示例中的团队、分工、翻校、术语、归档能力依据[版本说明](releases/1.0.0.md)；批注位置和文字依据[监修说明](chapter-issues.md)；参与入口依据[反馈说明](../SUPPORT.md)和[贡献指南](../CONTRIBUTING.md)；许可标识依据[许可证](../LICENSE)。
