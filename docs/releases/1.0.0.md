# PopRaKo Server 1.0.0

The first stable backend baseline for manga translation project management,
built with Rust 2024, Axum, Diesel, and PostgreSQL.

## Features

- Teams, worksets, comics, chapters, member invitations, assignments, and
  chapter workflow stages.
- Source pages, composite artwork, translation and revision units, artwork
  review issues, terminology management, and import/export APIs.
- Permanent comic archives with complete UTC-month JSON exports. Export
  generation and transfer share configurable memory, temporary-file, and
  concurrency budgets; exhausted capacity or budgets return HTTP 503.

## Compatibility and deployment

The API remains under `/api/v1`; its generated contract is recorded in
[OpenAPI](../swagger.json). User profiles support reads, updates, passwords,
and avatars. Account deletion is outside the supported interface:
`DELETE /api/v1/users/{user_id}` returns HTTP 405.

Runtime configuration uses defaults with optional TOML overrides. Unknown keys
and invalid explicit values fail startup. PostgreSQL and Cloudflare R2 remain
required runtime dependencies. See [the README](../../README.md) for setup.

Existing installations must reconcile their actual schema and migration history
against [database upgrade support](../database-upgrade-support.md) before
deployment. Application startup does not apply migrations. The single-root Git
history for 1.0.0 does not reset database history or replace upgrade procedures.

Release artifacts are built and published through GitHub Actions after CI,
independent approval, and production deployment for the final source commit.
The release retains source and binary archives, checksums, a CycloneDX SBOM,
and workflow provenance containing deployment evidence. See
[the release policy](../../RELEASE.md) for the acceptance sequence.
